All 11 Tables — Field-by-Field Explanation

Every field explained with its type, constraint, and purpose in SwiftRoute.

👤 Users
PKIdGUID, auto-generated. Uniquely identifies each user.
UQUsernamestring(100). Must be unique. Used for login.
UQEmailstring(256). Must be unique. Prevents duplicate accounts.
NNFullNameDisplay name shown in UI and auto-filled in booking.
ENUMRoleAdmin | Operator | Customer | PendingOperator
NNPasswordHashPBKDF2 salted hash. Never store plain password.
IDXCreatedAtUtcWhen the user registered. Stored in UTC.
-RowVersionbyte[]. Concurrency token. Prevents simultaneous updates.
🏢 BusOperators
PKIdGUID. Unique operator profile ID.
FKUserId→ Users.Id. Links operator profile to its user account. One-to-one.
NNCompanyNamestring(200). Set by admin on approval. e.g., "Sharma Travels".
-SupportPhonestring(30). Customer support contact. Optional.
-RowVersionConcurrency token.
🚌 Buses
PKIdGUID. Unique bus identifier.
FKOperatorId→ BusOperators.Id. CASCADE. Bus belongs to one operator. Delete operator → all buses deleted.
UQCodeUnique per operator. e.g., "BUS-01". Composite index on (OperatorId, Code).
NNRegistrationNumberLegal vehicle registration. e.g., "TN01AB1234".
ENUMBusTypeSeater=1, SemiSleeper=2, Sleeper=3, AC=4, NonAC=5
ENUMStatusAvailable=1, UnderRepair=2, NotAvailable=3. Booking only allowed if Available.
NNTotalSeatsint. Default 40. Used to generate seat numbers 1..N.
📍 Stops
PKIdGUID. Unique stop identifier.
UQCityCity name. e.g., "Chennai". Part of composite unique index with Name.
UQNameStop name. e.g., "Koyambedu Bus Stand". Unique constraint: (City, Name) together.
-Latitudedouble? Optional GPS coordinate for map features.
-Longitudedouble? Optional GPS coordinate for map features.
🗺️ BusRoutes
PKIdGUID. Unique route identifier.
FKOperatorId→ BusOperators.Id. CASCADE. Route belongs to operator.
UQRouteCodeUnique per operator. e.g., "CHN-BLR-01". Composite index on (OperatorId, RouteCode).
🔀 RouteStops (Junction Table)

Links Routes ↔ Stops in order. A route has many stops, a stop can appear in many routes.

PKIdGUID. Unique junction record.
FKRouteId→ BusRoutes.Id. CASCADE. Delete route → all its stops deleted.
FKStopId→ Stops.Id. RESTRICT. Cannot delete a stop that's in use.
UQOrderSequence position 1..N. Unique per route. Determines stop ordering.
-ArrivalOffsetMinint? Minutes from departure this stop is reached.
-DepartureOffsetMinint? Minutes from departure this stop departs.
🗓️ BusSchedules
PKIdGUID. Unique schedule identifier.
FKBusId→ Buses.Id. CASCADE. Delete bus → schedules deleted.
FKRouteId→ BusRoutes.Id. RESTRICT. Cannot delete route with active schedules.
UQDepartureUtcDateTime UTC. Unique per bus — one bus can't have two schedules at same time. Composite index (BusId, DepartureUtc).
NNBasePricedecimal(10,2). Price per seat. Max value 99,999,999.99.
NNIsCancelledByOperatorbool. Set to true when operator cancels. Blocks new bookings.
-CancelReasonstring? Reason shown to customers when cancelled.
🎫 Bookings
PKIdGUID. Unique booking identifier. Shown as reference #.
FKUserId→ Users.Id. RESTRICT. Cannot delete user with bookings.
FKScheduleId→ BusSchedules.Id. CASCADE. Delete schedule → bookings deleted.
ENUMStatusPending=1, Confirmed=2, Cancelled=3, Refunded=4, OperatorCancelled=5
NNTotalAmountdecimal(10,2). BasePrice × number of passengers.
👥 BookingPassengers
PKIdGUID. Unique passenger record.
FKBookingId→ Bookings.Id. CASCADE. Delete booking → passengers deleted.
NNNamestring(150). Full name of the traveller.
-Ageint? Optional. Used for age-based pricing if needed.
NNSeatNostring(10). e.g., "12A". Locked during booking transaction. Prevents double-booking.
💳 Payments
PKIdGUID. Unique payment record.
FKBookingId→ Bookings.Id. CASCADE. One-to-one. One booking = one payment.
ENUMStatusInitiated=1, Success=2, Failed=3, Refunded=4
NNAmountdecimal(10,2). Amount actually paid.
NNProviderReferencestring(100). Payment gateway reference. e.g., "PAY-1234567890".
📋 AuditLogs (standalone)

No FK constraints. Stores a snapshot of what happened. Even if the user is deleted, the audit trail remains.

PKIdGUID. Unique log entry.
ENUMLogType"Audit" (intentional writes) | "Error" (exceptions)
IDXUserIdGUID? Soft reference to Users. No FK so deleting user keeps logs.
IDXCreatedAtUtcIndexed for fast date-range filtering.
IDXLogTypeIndexed for fast Audit vs Error filtering.
-Detailstring(4000)? Full stack trace for Error logs.
-DurationMslong? Milliseconds — performance monitoring.

All 10 Relationships Explained

What each FK means, the cardinality, and what happens when you delete the parent.

From (child)To (parent)TypeDelete behaviourWhat it means in SwiftRoute
BusOperators.UserId Users.Id 1 : 1 RESTRICT Every operator has exactly one user account. Created by admin when approving a PendingOperator. Cannot delete the user while this profile exists.
Buses.OperatorId BusOperators.Id N : 1 CASCADE Each bus belongs to one operator. If the operator is removed from the system, all their buses are deleted automatically.
BusRoutes.OperatorId BusOperators.Id N : 1 CASCADE Each route belongs to one operator. Operator manages their own routes. Deleting operator removes all routes.
RouteStops.RouteId BusRoutes.Id N : 1 CASCADE A route has many ordered stops. Deleting the route removes all its stop assignments.
RouteStops.StopId Stops.Id N : 1 RESTRICT A stop can appear in many routes. Admin CANNOT delete "Chennai Central" if any route still uses it. Prevents accidental data loss.
BusSchedules.BusId Buses.Id N : 1 CASCADE A bus has many departure schedules. Removing a bus deletes all its scheduled trips. Also has unique constraint: one bus cannot have two schedules at same departure time.
BusSchedules.RouteId BusRoutes.Id N : 1 RESTRICT A schedule uses one route. Cannot delete a route that has live schedules. Operator must cancel schedules first.
Bookings.UserId Users.Id N : 1 RESTRICT Each booking is made by one customer. Cannot delete a user account that has booking history. Preserves audit trail.
Bookings.ScheduleId BusSchedules.Id N : 1 CASCADE Each booking is for one schedule. If a schedule is fully deleted, its bookings are removed. In practice, operator uses IsCancelledByOperator flag instead of deleting.
BookingPassengers.BookingId Bookings.Id N : 1 CASCADE Each booking has one or more passengers. SeatNo per passenger is locked during a Serializable DB transaction to prevent two people booking the same seat.
Payments.BookingId Bookings.Id 1 : 1 CASCADE Each booking has exactly one payment record. Created when booking is made (Initiated), updated to Success when customer pays. HasForeignKey is on Payment side.

Database Terms Glossary

Every term used in the ER diagram explained simply.

🔑 Primary Key (PK)
A column that uniquely identifies each row. No two rows can have the same value. Cannot be NULL.
In SwiftRoute: every table has Id (GUID) as PK. EF Core generates a new GUID automatically when you create a record.
🔗 Foreign Key (FK)
A column in one table that points to the PK of another table. Creates a relationship between tables.
Bookings.UserId → Users.Id means every booking must reference a valid user. You cannot create a booking for a non-existent user.
✅ Unique Constraint (UQ)
Ensures no two rows have the same value in that column (or combination of columns). Unlike PK, can be any column.
Users.Username is UQ — two people can't register as "john123". Buses.(OperatorId, Code) is UQ — same operator can't have two buses with code "BUS-01".
📊 Index (IDX)
A data structure that makes searching faster. Without index, DB scans every row. With index, it jumps directly to matching rows.
AuditLogs.CreatedAtUtc is indexed so filtering by date range (last 7 days) is fast even with millions of log entries.
🎭 Enum
A fixed set of named integer values. Stored as int in DB, used as named value in code.
BookingStatus.Pending=1, Confirmed=2, Cancelled=3. DB stores 1, but code says booking.Status == BookingStatus.Confirmed — readable and type-safe.
🌊 CASCADE Delete
When you delete the parent row, all child rows that reference it are automatically deleted too.
Delete a Bus → its BusSchedules are deleted → their Bookings are deleted → Passengers and Payments deleted. One delete cleans the whole chain.
🛑 RESTRICT Delete
Prevents deleting a parent row if any child rows reference it. You must delete or update children first.
Cannot delete a Stop if any RouteStop references it. Admin must first remove that stop from all routes before deleting it.
1 : 1 (One-to-One)
Each row in Table A has at most one matching row in Table B, and vice versa.
Users ↔ BusOperators: One user has one operator profile. One operator profile belongs to one user. Booking ↔ Payment: one booking = one payment.
1 : N (One-to-Many)
One row in Table A can have many matching rows in Table B. Each row in B has exactly one match in A.
One BusOperator has many Buses. One Booking has many BookingPassengers (one per seat selected).
M : N (Many-to-Many)
Many rows in A can relate to many rows in B. Implemented via a junction/bridge table.
Routes ↔ Stops is M:N: one route has many stops, one stop appears in many routes. RouteStops is the junction table with extra data (Order, offsets).
🕐 RowVersion
A byte[] column automatically updated by the DB on every save. EF Core checks this when saving — if it changed since you read it, another user modified the row first and EF throws an exception.
Prevents two operators updating the same bus simultaneously. The second save is rejected with DbUpdateConcurrencyException.
🌐 GUID
Globally Unique Identifier — a 128-bit value that is unique across the entire world. Generated client-side or server-side.
All PKs in SwiftRoute use GUIDs. Safer than auto-increment int: attackers can't guess /api/bookings/2 or /api/bookings/3 to enumerate your data.
🕰️ UTC DateTime
All timestamps stored in UTC (Coordinated Universal Time) — timezone neutral. Converted to local time only in the UI.
DepartureUtc in BusSchedules is stored as UTC. Angular formats it with toLocaleString('en-IN') to show it in Indian Standard Time to the user.
🔒 Serializable Transaction
The strictest transaction isolation level. Locks all rows involved until the transaction completes. No other transaction can read or write those rows.
BookingService uses Serializable transaction when checking and reserving seats. Two users cannot book Seat 5A at the same time — one will fail.
📦 Soft Delete
Instead of physically deleting a row, set IsDeleted = true. Row stays in DB but is filtered out of normal queries.
BaseEntity has IsDeleted field. Not fully implemented in v1 but the foundation is there for future use.
